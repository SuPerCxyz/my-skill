## Why

The KVM skill behavior is now hardened, but its explanatory prose still mixes Chinese and English unevenly. Normalizing language improves readability and reduces interpretation cost without changing command or behavior contracts.

## What Changes

- Keep the English trigger description, pure-English H1 headings, bilingual H2/H3 headings, and English code/config identifiers.
- Rewrite explanatory prose in Simplified Chinese with necessary English technical terms and consistent spacing.
- Preserve every validated Shell command, variable, YAML key, state value, mode, safety gate, and completion behavior.
- Re-run skill-creator review for triggering, progressive disclosure, duplication, conflicts, and instruction precision.

## Capabilities

### New Capabilities

无.

### Modified Capabilities

无. This is a documentation-only language normalization.

## Impact

- Modifies existing KVM skill documentation and the root README description only.
- Updates project-local architecture fingerprint because tracked skill text changes.
- Does not add/delete skill files, modify the main KVM spec, or execute KVM operations.
